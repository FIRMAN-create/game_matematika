# BREAK THE CODE: ESCAPE ROOM MATEMATIKA
> Game edukasi 2D interaktif — Fungsi Komposisi & Invers — React + Vite + Phaser 3

## Cara Menjalankan

```bash
npm install
npm run dev
```

Buka browser di http://localhost:3000

## Cara Bermain

| Kontrol | Fungsi |
|---------|--------|
| `W` / `↑` | Gerak atas |
| `S` / `↓` | Gerak bawah |
| `A` / `←` | Gerak kiri |
| `D` / `→` | Gerak kanan |
| `E` | Interaksi dengan terminal |
| `ESC` | Pause menu |

Mobile: Gunakan D-pad virtual di layar.

## Struktur Level

| Level | Topik | Soal | Skor |
|-------|-------|------|------|
| 1 — Basic Access | Nilai Fungsi | h(x)=2x+3, h(4)=? | 20 |
| 2 — Double Encryption | Komposisi Fungsi | (f∘g)(x), (f∘g)(2) | 30 |
| 3 — Final Decryption | Komposisi + Invers | E(x), E⁻¹(x), Dekripsi KUNCI | 50 |

## Teknologi

- **React 18** + **Vite 5** — struktur aplikasi
- **Phaser 3** — game engine 2D (canvas, physics, scene)
- **CSS Custom Properties** — design system sci-fi neon
- **Google Fonts** — Orbitron, Share Tech Mono, Inter

## Materi Matematika

Game mencakup:
- Fungsi dan nilai fungsi
- Komposisi fungsi: (f∘g)(x) = f(g(x))
- Fungsi invers: jika y=f(x) maka x=f⁻¹(y)
- Enkripsi & dekripsi berbasis fungsi
- Konversi huruf-angka (A=1, ..., Z=26)
